# LinkedIn Project Post

## Full Version

I built an exploratory scientific visualization project focused on car aerodynamics using ParaView, OpenFOAM workflows, Python, VTK, and PyVista.

The project creates a beginner-friendly CFD-style pipeline for visualizing airflow around a simplified car body. It includes pressure maps, velocity slices, streamlines, vector glyphs, turbulence proxies, wake iso-surfaces, rotating camera animations, and drag/lift metric plots.

What I practiced:

- Loading and exporting VTK scientific datasets
- Creating scalar and vector field visualizations
- Using ParaView-style workflows for slices, contours, streamlines, glyphs, and animation
- Connecting Python visualization automation with OpenFOAM post-processing concepts
- Explaining aerodynamic wake formation, pressure drag, turbulence, and Reynolds number in an accessible way

This is not a new CFD solver. It is a practical scientific visualization project designed to show how raw flow fields can become clear engineering visuals and aerodynamic interpretation.

Tools: Python, PyVista, VTK, NumPy, Matplotlib, ParaView, OpenFOAM, Docker
